# أطلس | المشافي العسكرية في سوريا

واجهة عربية بخريطة تفاعلية للمحافظات السورية وصفحات للمشافي وأقسامها وخدماتها، مستوحاة من الهوية البصرية السورية الجديدة.

جميع أسماء المشافي ومواقعها وأعدادها وبياناتها تجريبية. ليست هذه المنصة دليلاً طبياً فعلياً.

## الوظائف

- خريطة SVG للمحافظات الأربع عشرة، مع انتقال إلى خريطة المحافظة.
- توزّع المشافي وبطاقات التفاصيل والخدمات والتجهيزات.
- بحث موحد يدعم العربية، مع اختصار Ctrl/⌘ + K.
- تصفية حسب الخدمات، وتعديل السجلات وحفظها داخل المتصفح.
- تصميم متجاوب واتجاه RTL ودعم تقليل الحركة.

## التشغيل محلياً

يتطلب Node.js 22 وnpm.

```sh
npm ci
npm run dev
```

## الفحص والبناء

```sh
npm run check:data
npm run check:search
npm run build
```

ملفات النشر في `dist/`. المسارات نسبية لتعمل تحت اسم المستودع على GitHub Pages وعند جذر النطاق. صفحات المحافظات تستخدم روابط hash لتدعم التحديث والمشاركة دون الحاجة إلى خادم.

## النشر إلى GitHub Pages

1. ارفع ملفات المشروع إلى الفرع `main` في مستودعك.
2. افتح **Settings → Pages** واختر **GitHub Actions** من قائمة **Source**.
3. شغّل **Deploy GitHub Pages** من تبويب Actions، أو ادفع تحديثاً إلى `main`.
4. بعد نجاح مهمة `deploy`، يظهر رابط الموقع في تبويب Pages ونتيجة النشر.

يتولى ملف `.github/workflows/deploy-pages.yml` الفحص والبناء والنشر تلقائياً. يستخدم `GITHUB_TOKEN` الذي يوفره GitHub Actions؛ لا تضع مفاتيح أو رموز وصول داخل الكود.

GitHub Pages في المستودعات الخاصة يعتمد على خطة الحساب. الموقع المنشور على Pages قد يكون متاحاً للجمهور، حتى لو كان المستودع خاصاً؛ تحقق من إعدادات الوصول في حسابك.

## التقنيات

React، TypeScript، Vite، SVG وD3 Geo، MapLibre GL، Motion، Radix UI، cmdk، Sonner.

## البيانات والموارد

- الحدود الجغرافية وموارد الهوية والخط: [Syrian Zone](https://syrian.zone/syid).
- الأيقونات الطبية وأيقونات المعالم في الواجهة: SVG مخصصة للمشروع.
- خريطة الطرق: Esri World Street Map ومساهموها، مع حقوق المصدر داخل الخريطة. تتطلب طبقة الطرق اتصالاً بالإنترنت.
- خط حيّاكم الله مقدم في المرجع بديلاً مجانياً لقمرة؛ راجع شروط الموارد قبل استخدامها تجارياً أو مؤسسياً.
- دُمج الحد الداخلي بين جزأي القنيطرة مع الحفاظ على المساحة الأصلية. يتحقق `check:data` من ذلك ومن بقاء المشافي التجريبية داخل المحافظات.

التخزين محلي في المتصفح؛ لا توجد قاعدة بيانات مشتركة أو منظومة حسابات داخل التطبيق.
